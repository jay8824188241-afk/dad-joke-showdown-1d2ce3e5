A tiny Node program that writes one original dad joke to `/output/entry.txt`: a pencil, a barbecue, and a pun on drawing the line at the steaks. The joke is 81 characters, well under the 200-character cap, and reads aloud like a father telling it across the dinner table.

## Run it

```sh
node main.ts
```
